## Requirements

The following software must be downloaded and installed separately:

- Kingdom Hearts II Final Mix (Steam version)
- KH2 Tracker
- LiveSplit
- KH2 Load Remover

The launcher does not download, install, or configure these programs automatically.

You must also have the following Steam Deck components:

- SteamOS
- Steam Linux Runtime Sniper
- Gamescope
- MangoHud
- xdotool
- Python 3

## Installation

1. Download and install KH2 Tracker.
2. Download and install LiveSplit.
3. Download and install KH2 Load Remover.
4. Ensure `KhTracker.exe` and `LiveSplit.exe` are located somewhere under your home directory.
5. Save the launcher script as `kh2-randomizer-auto-launcher.sh`.
6. Make the script executable.

## Usage

1. Launch the script from Steam Deck Desktop Mode.
2. The launcher automatically detects your KH2 installation, Proton version, and required executable paths.
3. KH2 launches through Gamescope.
4. Wait until the actual KH2 title screen appears.
5. Press ENTER in the launcher terminal.
6. KH2 Tracker and LiveSplit launch automatically in the shared Wine virtual desktop.

**Important:** KH2 Load Remover must be installed separately. The launcher does not install it.
